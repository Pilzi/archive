# Twitch Speedrun

A browser extension that opens a Twitch stream as soon as the streamer goes
live, so you're the first one there.

- [v1](v1/) – first version, uses the Twitch API (2021)
- [v2](v2/) – rewrite without the Twitch API, no setup needed (2023)

Each version has a `chrome` and a `firefox` folder, see its README for how to
load it.
